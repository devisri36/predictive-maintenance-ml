# Predictive Maintenance for Industrial Machines

## Overview
This project predicts industrial machine failures using Machine Learning based on sensor data such as temperature, torque, rotational speed, and tool wear.

## Features
- Machine failure prediction
- Random Forest ML model
- Streamlit web interface
- Data preprocessing
- Model evaluation

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Dataset
AI4I 2020 Predictive Maintenance Dataset

## How to Run

### Install dependencies
```bash
pip install -r requirements.txt
```

### Train model
```bash
python train_model.py
```

### Run app
```bash
streamlit run app.py
```
